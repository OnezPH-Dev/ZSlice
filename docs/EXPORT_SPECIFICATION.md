# Export specification

PDF pages use exact selected physical sheet dimensions (72 points/inch) at 100% printing scale. Raster sources and source PDFs are rendered through a shared sheet renderer. Source PDFs are currently rasterized: vector preservation is a future enhancement, never implied. Raster dimensions = inches * effective DPI. Automatic DPI respects available source resolution, capped at 300. Process one tile at a time; enforce a per-sheet memory limit. ZIP contains Page_001.png or JPEG entries. DOCX is a valid OOXML package with one page image per section/page and explicit page dimensions; text is not editable. Preview visibility and export visibility of guides are independent. Export temporary output is finalized only after success; cancellation removes staging files. Native printing consumes the same generated PDF. Always print at actual size.

Optional text layers are drawn after the image and before sheet/guide overlays by the shared renderer. Text-only posters are supported. Automatic resolution selects 300 DPI when text is present to retain glyph detail. Text remains editable in .zslice project metadata; exported page images and image-based PDF/DOCX content are rasterized.
