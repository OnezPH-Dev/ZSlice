# Slicing engine

Canonical units: millimetres. Usable width = paper width - left margin - right margin. Overlap is uniform between adjacent sheets; advance = usable dimension - overlap. Coverage = usable dimension * count - overlap * (count - 1). Custom-size count = max(1, ceil((poster dimension - overlap) / advance)). Last sheet may contain unused white area. Grid counts range 1..20. Reject nonfinite/negative dimensions, nonpositive printable area, overlap >= either printable dimension and more than 400 sheets. Row-major and column-major order change numbering, not geometry. Each tile references a physical poster rectangle, full sheet dimensions and printable rectangle. Continuation seams use right/bottom trim boundaries, with explicit edge selection; guides never reuse the editor grid. Preview and export consume this plan.

Cut guides use the midpoint of duplicated overlap bands. Default selected edges are right/bottom interior seams; top/left can be selected independently. Outer poster boundaries never become interior cut guides. Automatic DPI accounts for source crop, quarter-turn rotation, aspect-fit and artwork scale, then clamps to 72–300 DPI; a low-detail warning is shown when the source cannot supply the requested export detail.
